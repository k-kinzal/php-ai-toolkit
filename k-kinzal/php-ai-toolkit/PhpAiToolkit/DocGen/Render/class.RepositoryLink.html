final class RepositoryLink

Renders the links that lead from the site back to the code it documents.

A generated site is the read side of a repository, so every page carries the way back to it, and a package names the repository it is published from. The link is written with the address it leads to rather than with a word for it: a reader who is about to leave the site is told where to.
