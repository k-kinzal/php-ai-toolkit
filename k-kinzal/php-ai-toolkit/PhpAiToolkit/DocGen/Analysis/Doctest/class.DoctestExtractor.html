final class DoctestExtractor

Extracts executable examples from PHPDoc blocks.

The grammar matches k-kinzal/doctest-php exactly: at-example blocks run until the next tag line, and only fences whose info string is exactly "php" are recognized, so every extracted example is runnable by doctest.
