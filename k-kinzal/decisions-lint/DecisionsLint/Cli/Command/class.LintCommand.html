abstract class LintCommand
    extends Command

A decisions-lint console command: shared options, error reporting and exit codes.

Every failure is reported in one line on standard error that names the problem and how to fix it, and exits 2, so a caller can tell a broken command line, configuration or provider apart from a violated rule, which exits 1.
