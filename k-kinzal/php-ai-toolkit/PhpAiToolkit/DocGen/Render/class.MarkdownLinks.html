final class MarkdownLinks

Resolves Markdown links that point at documents of the same package.

A repository keeps its prose in Markdown files that link to each other by relative path. Those paths mean nothing in the generated site, so they are resolved here against the documents that were rendered, turning a written cross-reference into a working link. Targets outside that set stay unresolved and are rendered as plain text by the caller.
