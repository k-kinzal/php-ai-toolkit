final class SymbolDescription

Says in one sentence what one documented symbol is.

This is what a page is previewed by rather than what it is read by: the summary line its author wrote is the sentence, and a symbol documented with nothing is named by what it is and where it lives, so a shared link is never previewed by an empty description.
