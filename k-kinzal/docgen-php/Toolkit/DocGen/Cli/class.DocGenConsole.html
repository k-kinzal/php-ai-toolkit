public function doRun(InputInterface $input, OutputInterface $output): int
source§

Runs the docgen command.

The input and output are configured here as well as in run(), so a caller that runs the console in-process still gets --quiet, --verbose and --no-ansi honoured. The verbosity Symfony Console leaves in the environment for child processes is put back afterwards, so one in-process run does not silence the next.
