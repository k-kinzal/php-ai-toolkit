final class RulePhpDocParser

Parses rule-owned PHPDoc text with phpdoc-parser 1 or 2.

Version 2 adds a parser configuration argument that version 1 does not accept. Reflecting the lexer constructor lets the rule use the declared API of either installed major without naming a version-specific class.
