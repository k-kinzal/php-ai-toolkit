final class ForbidEmptyCatchRule
    implements Rule<Catch_>

Forbids catch blocks with an empty body.

An empty catch block silently discards the failure it captured. The exception must be rethrown, wrapped, logged, or replaced by a deliberate fallback so the failure stays observable.
