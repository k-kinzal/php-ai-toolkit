final class DocGenConfig

Immutable DocGen configuration, as one command line described it.

The configuration deliberately covers only the documented code scope and the output location; page content and design are fixed by the generator. Everything here is named by an option of the run, so what a site was generated from is the command that generated it, and a continuous integration job can pass the values only it knows, such as the address the site is published at.
