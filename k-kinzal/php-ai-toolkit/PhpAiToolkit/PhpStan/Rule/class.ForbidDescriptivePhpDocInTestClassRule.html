final class ForbidDescriptivePhpDocInTestClassRule
    implements Rule<ClassLike>

Forbids descriptive (non-annotation) PHPDoc text in test classes.

In restricted test namespaces, PHPDoc on classes and methods must contain only @tags (e.g. @dataProvider, @extends). Descriptive prose text is forbidden because test names and class names should be self-documenting.
