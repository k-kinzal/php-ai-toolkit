final class ClassLikeMerger
Restricted visibility: declared "@visibility Toolkit\DocGen\Compare". Code outside that scope must not name this declaration.

Merges the two revisions of one class-like symbol into one page model.

The merged symbol carries what the head declares plus what the base declared and the head dropped, so a page can show a removal instead of silently losing it, and every part of it is marked in the diff index.
