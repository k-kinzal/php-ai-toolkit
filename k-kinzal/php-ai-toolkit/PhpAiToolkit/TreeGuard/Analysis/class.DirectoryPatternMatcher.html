final class DirectoryPatternMatcher

Matches rule path patterns against relative directory paths segment by segment.

A "**" segment matches zero or more path segments, so "src/**" also matches "src" itself. Every other segment is matched with fnmatch against exactly one path segment, so "*" never crosses a "/" boundary. Patterns are anchored at both ends.
