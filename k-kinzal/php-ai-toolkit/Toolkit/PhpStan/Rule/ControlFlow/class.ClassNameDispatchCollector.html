final class ClassNameDispatchCollector
    implements Collector<Node, array{roots: list<string>, named: list<string>, catchAll: bool, line: int, construct: string}>

Records the class-name dispatches the analysed code contains.

match ($shape::class) is the one form in which PHP states what a branch table is answering for. The subject names the object, so the set of classes to cover follows from that object's type, and every branch has to be a class name, so no unrelated condition can enter the table. match (true) { $shape instanceof Circle => ... } states neither: its subject is a constant and its branches take any condition at all, which is why a hierarchy is never read out of that form.

A subject whose classes are all final resolves to literal class names on its own and is left to the rule that reads values straight out of the type.
