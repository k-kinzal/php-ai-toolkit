final class ScopeProblemReader
Restricted visibility: declared "@visibility parent". Code outside that scope must not name this declaration.

Explains why an @visibility value cannot be honoured as written.

A scope that resolves to nothing is left unenforced on purpose, so a tag nobody can honour has to be reported here or it would silently drop the restriction it was written to add.
