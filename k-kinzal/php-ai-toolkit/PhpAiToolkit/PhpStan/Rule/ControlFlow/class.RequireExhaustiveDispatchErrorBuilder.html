classRequireExhaustiveDispatchErrorBuilder

PhpStanRulesrc/PhpStan/Rule/ControlFlow/RequireExhaustiveDispatchErrorBuilder.php:25
final class RequireExhaustiveDispatchErrorBuilder

Builds the PHPStan errors for a dispatch that leaves values of a closed type out.

The wording lives here rather than in the rules that report it. A subject whose type carries its own values and a subject reached through a class name are the same mistake seen from two sides, and they have to read the same way. The file is named only by the rule that reports after the analysis, where the error no longer sits in a file PHPStan is reading.
