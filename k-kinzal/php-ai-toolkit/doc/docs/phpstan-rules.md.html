PHPStan Rules

Custom PHPStan rules provided by php-ai-toolkit. Each rule detects anti-patterns that actually occur in AI-generated code.

General

Rules applied to all code.

RuleDescriptionError Identifier
ForbiddenCommentRuleForbids @phpstan-ignore and @infection-ignore-all commentscustomRules.phpstanIgnoreComment, customRules.infectionIgnoreAllComment
ForbiddenMagicMethodCallRuleForbids direct calls to magic methodscustomRules.forbiddenMagicMethodCall
ForbiddenNamespaceRuleForbids configured namespace prefixes such as Tests\Support, Tests\Helper, and Tests\UtilcustomRules.forbiddenNamespace
OverrideMustHaveAttributeRuleRequires #[Override] attribute on overridden methodscustomRules.overrideMustHaveAttribute
SrcUnitTestPairRuleEnforces 1:1 pairing between src/ classes and tests/Unit/ test classescustomRules.srcUnitTestPair
RequirePhpDocOnPublicApiRuleRequires PHPDoc on all public API elementscustomRules.requirePhpDocOnPublicApi
RequireExampleOnPublicApiRuleRequires a runnable @example on declarations marked @visibility publiccustomRules.requireExampleOnClass, customRules.requireExampleOnMethod, customRules.requireExampleOnProperty, customRules.requireExampleOnConstant, customRules.requireExampleOnEnumCase
ForbidNonDocCommentRuleForbids /* */ and # comments everywhere, and // comments outside catch blocks and array literals; /** */ PHPDoc is allowedcustomRules.forbidNonDocComment
ForbidSingleLinePhpDocRuleForbids single-line PHPDoc on public elements; requires multi-line formatcustomRules.forbidSingleLinePhpDoc
ForbidClassLikeNameSuffixRuleForbids configured suffixes on class, interface, trait, and enum namescustomRules.forbiddenClassLikeNameSuffix
NoNonPublicMethodRuleForbids private methods and forbids protected methods outside abstract classes, traits, and override methodscustomRules.nonPublicMethod
ForbidEmptyCatchRuleForbids catch blocks with an empty bodycustomRules.emptyCatch
RequireThrowsTagOnDirectThrowRuleRequires @throws for exceptions thrown directly in a method and not caught within itcustomRules.missingThrowsTag
RequireExceptionChainingRuleRequires new exceptions thrown inside catch blocks to chain the caught exceptioncustomRules.unchainedRethrow
ForbidBroadCatchRuleForbids catching Throwable, Exception, and the LogicException/Error families outside configured boundary pathscustomRules.broadCatch
ForbidGenericThrowsTagRuleForbids @throws \Exception and @throws \Throwable tagscustomRules.genericThrowsTag
RequireExhaustiveDispatchRuleRequires a switch or match that names its subject — match ($suit), or match ($payment::class) for a sealed hierarchy — to name a branch for every value that subject can hold, the way Rust and Kotlin check a match over a closed typecustomRules.exhaustiveDispatch, customRules.exhaustiveDispatchDefault

Test Class

Rules applied to test classes in the Tests\Unit / Tests\Integration namespaces. Rules marked with * apply to all Tests\ namespaces.

RuleDescriptionError Identifier
NoPropertyInTestClassRuleForbids property declarations in test classescustomRules.noPropertyInTestClass
NoClassConstantInTestClassRuleForbids class constants in test classescustomRules.noClassConstantInTestClass
NoPrivateMethodInTestClassRuleForbids private methods in test classescustomRules.noPrivateMethodInTestClass
NoHelperMethodInTestClassRuleForbids methods other than test/provider/overridecustomRules.noHelperMethodInTestClass
NoControlFlowInTestMethodRuleForbids control flow statements in test methodscustomRules.noControlFlowInTestMethod
NoTraitUseInTestClassRuleForbids trait usage in test classescustomRules.noTraitUseInTestClass
NoReflectionInTestClassRule *Forbids Reflection API usage in test classescustomRules.noReflectionInTestClass
NoRedundantAssertInstanceOfRule *Forbids redundant PHPUnit assertInstanceOf() calls for values with one statically-known typecustomRules.noRedundantAssertInstanceOf
NoBrokenCodeExpectationRule *Forbids expectException() / expectExceptionObject() for Throwable and the LogicException/Error familiescustomRules.noBrokenCodeExpectation
PhpUnitMockApiRule *Restricts mock API and enforces interface-only mockingcustomRules.phpUnitMockApi
ForbidDescriptivePhpDocInTestClassRuleForbids descriptive PHPDoc text in test classescustomRules.forbidDescriptivePhpDocInTestClass
TestNamingConventionRuleEnforces naming conventions for test methods and data providerscustomRules.testNamingConvention

Disabling Rules

To disable a specific rule, suppress its error identifier in your project's phpstan.neon:

parameters:
    ignoreErrors:
        - identifier: customRules.infectionIgnoreAllComment
