final class TreeGuardPathResolver

Resolves absolute and project-relative paths for TreeGuard directory scanning.

The project root is addressed as "." both in the configured paths and in the relative paths reported for it, so every directory below it keeps the same root-relative form whether the scan started at the root or deeper.
