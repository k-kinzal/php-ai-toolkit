final class DispatchInspector

Inspects one switch statement or match expression for the values it leaves out.

A match without a "default" arm is left to PHPStan, which already reports the values such a match does not handle; reporting them a second time would only duplicate that error. Everything else — a switch either way, and a match whose "default" hides the gap — is inspected here.
