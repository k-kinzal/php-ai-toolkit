final class PhpParserBridge

Creates a PHP parser for both nikic/php-parser 4 and 5.

The two major versions expose different factory methods, so the factory is inspected with reflection and the available method is invoked. This keeps the bridge valid for either major version without referencing methods that only one of them ships.
