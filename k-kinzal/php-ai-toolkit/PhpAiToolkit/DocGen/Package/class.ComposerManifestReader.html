public function repository(mixed $data): string
100%source§

Reads where one manifest says its sources can be browsed.

A package states that under "support.source", which is what composer itself links a package to its code with. Where a package states no source, its "homepage" is the only address it offers a reader, so it stands in for one; a package that states neither is documented without a link to anywhere.
