public function repositoryFor(DocGenConfig $config, list<DiscoveredPackage> $packages): ?string
source§

Determines the repository the documented project lives in.

A project that configures an address means that one: it is the answer where a repository has moved, where the manifest of the project says nothing, and where the site is generated from a checkout that is not the published one. Otherwise the root package answers for the project, because a package already declares where its sources are browsable.

source§

Warns about vendor globs that selected no package of one kind.

Vendor globs match composer package names, so a directory name such as "vendor" silently selects nothing without this warning. A glob also selects nothing when it names a dev dependency while the runtime globs are checked, or the other way round.
