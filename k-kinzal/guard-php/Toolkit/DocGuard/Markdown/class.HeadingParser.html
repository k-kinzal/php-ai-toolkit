final class HeadingParser

Extracts the document headings from Markdown source.

Only the block structure that decides whether a line is a heading is parsed: ATX and setext headings, fenced code blocks with backticks and tildes, HTML blocks, list items, block quotes, and YAML front matter. Inline content is kept verbatim in the heading text.
