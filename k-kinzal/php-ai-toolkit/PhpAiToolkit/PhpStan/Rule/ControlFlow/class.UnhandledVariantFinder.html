final class UnhandledVariantFinder

Names the values of a closed type that no branch of a dispatch claims.

The analyzer already knows how to take a value out of a type once a condition on it is false, so the branches are replayed as false one after another and whatever the subject can still be afterwards is what the dispatch left out.

100%source§

Returns the values the branches leave unclaimed, in the order the type lists them.

A dispatch that claims none of the values is reported as claiming all of them: it is either a comparison that happens to sit on a closed type, or a subject the analyzer cannot narrow, and neither is a half-finished dispatch worth pointing at.
