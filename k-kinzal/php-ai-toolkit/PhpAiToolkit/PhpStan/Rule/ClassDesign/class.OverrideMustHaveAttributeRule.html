classOverrideMustHaveAttributeRule

PhpStanRulesrc/PhpStan/Rule/ClassDesign/OverrideMustHaveAttributeRule.php:23
final class OverrideMustHaveAttributeRule
    implements Rule<ClassMethod>

Requires #[\Override] on methods that override a non-abstract parent method.

Implementing an abstract parent method is an implementation rather than an override, so it is not reported. Neither are the methods PHP refuses the attribute on; see OverridableMethodPolicy for which ones those are and why.
