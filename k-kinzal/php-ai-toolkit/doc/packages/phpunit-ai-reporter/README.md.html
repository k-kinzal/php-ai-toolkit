phpunit-ai-reporter

AI-readable PHPUnit reporting and PHPDoc example tests.

Part of php-ai-toolkit. Use a Composer path repository pointing to packages/* in a checkout until package releases are published. For development versions, set minimum-stability to dev and prefer-stable to true in the consuming project, or explicitly require each local dependency at dev-main.

composer require --dev k-kinzal/phpunit-ai-reporter:dev-main

See the guide. Run the monorepo tests and strict lint checks from the repository root. Existing Toolkit\ namespaces are retained.
