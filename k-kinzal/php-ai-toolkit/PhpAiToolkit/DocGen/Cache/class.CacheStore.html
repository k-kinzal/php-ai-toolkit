final class CacheStore

Reads and writes the cache files of one generation run.

A cache is an optimization and never an obligation: a file that cannot be read is read as an empty cache, and a file that cannot be written is reported to the caller rather than thrown, because a run that produced the site is a run that succeeded even when it could not remember it.

Writes one cache file, replacing it in a single step.

The payload is written next to its destination and renamed onto it, so a run interrupted while writing leaves the previous cache intact instead of a half-written one that the next run would read.
