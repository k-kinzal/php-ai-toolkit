classSchemaValidator

packages/decisions-lint/src/Config/SchemaValidator.php:17
final class SchemaValidator

Checks a decoded YAML document against one of the shipped JSON schemas.

It implements the keywords those schemas use: $ref, allOf, type, const, enum, required, properties, additionalProperties, propertyNames, items, minItems, maxItems, minimum, maximum, minLength and pattern. The first problem stops validation and is reported with its path and how to fix it.
