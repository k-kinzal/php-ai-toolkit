final class ThrowSiteVisitor
    extends NodeVisitorAbstract

Collects throw statements that escape the traversed statement list.

Tracks enclosing try/catch nesting so that a throw inside a try block records the catch types guarding it, while throws inside catch and finally blocks are not protected by their own try. Nested closures, arrow functions, and anonymous classes are skipped because their throws do not escape the enclosing method at declaration time.
