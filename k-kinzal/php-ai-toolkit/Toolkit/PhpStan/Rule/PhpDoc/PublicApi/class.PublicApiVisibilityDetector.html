final class PublicApiVisibilityDetector

Detects the declarations a PHPDoc block states are public API.

The statement is the "@visibility public" tag. Leaving the tag off also leaves a declaration reachable from everywhere, but it says nothing about intent; writing the tag is how a project declares that a symbol is part of the surface other code is invited to use, and that is the surface examples are required on.

Reports whether the PHPDoc block declares the symbol public API.

A tag only counts where PHPDoc puts one, at the start of a comment line, so prose that names the tag while explaining it is text and not a declaration.
