final class AiTestReporterExtension
    implements Extension

PHPUnit extension that provides dual-mode test result reporting.

AI mode — replaces progress/result with structured plain text. Human mode — supplements PHPUnit's default output on STDERR.

Not compatible with ParaTest; skips bootstrap when running inside a ParaTest worker process.
