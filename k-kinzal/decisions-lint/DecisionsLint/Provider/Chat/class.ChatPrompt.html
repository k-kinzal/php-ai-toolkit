final class ChatPrompt

Turns an inquiry into a chat conversation and the JSON schema the model's answer must follow.

A generative chat model has no decision endpoint, so the questions are written into the prompt and the answer is constrained to one JSON object with one entry per question: a probability for a predicate, an option and a confidence for a choice, a level and a confidence for a score.
