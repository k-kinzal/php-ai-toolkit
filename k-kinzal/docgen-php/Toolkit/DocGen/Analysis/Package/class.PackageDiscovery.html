final class PackageDiscovery

Discovers the composer packages selected by the DocGen configuration.

Project packages come from directory globs relative to the project root; a repository without a root composer.json is supported because glob entries without a manifest are skipped. Vendor packages are added afterwards: the "vendor" globs select installed runtime dependencies and the "vendor_dev" globs select installed dev dependencies.
