What the two chat fakes share: rebuilding the questions from the answer schema and writing the JSON answer a chat model would.

The prompt text is free-form, so the fakes read the questions from the schema instead: each property is a question whose type follows from its fields, and whose options or level count follow from the enum or maximum.
