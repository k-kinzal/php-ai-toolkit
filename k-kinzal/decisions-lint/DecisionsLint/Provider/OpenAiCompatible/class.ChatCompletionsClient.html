final class ChatCompletionsClient

The OpenAI chat completions API as LocalAI, vLLM, llama.cpp and similar servers implement it: POST /v1/chat/completions.

A request carries the model, the messages, a zero temperature and a response_format of type json_schema with the answer schema. The response carries choices, the first of which holds the assistant message.
