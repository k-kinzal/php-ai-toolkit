skills/guard/references/documentation.md

Markdown documents

Use guard rules --query=documentation to inspect declarations and guard check --query=documentation to inspect findings. All built-in document findings are required and need manual edits; fix does not rewrite Markdown.

FindingWhat to inspect
Missing, unexpected, renamed, moved, or changed-level headingDeclared heading text, level, and order; move the section with its content.
Missing or unexpected outline headingThe allowed headings at the reported outline position.
documentation.undeclared_documentdocumentation.scan and the declarations under documentation.files.
documentation.missing_documentThe declared file path and whether it was moved or removed.
Missing or unexpected badgeLabels, URL patterns, and badge order directly below the title.
documentation.unexpected_contentExact declared bytes, including the final newline.

Preserve document content when restoring structure. Change declarations when the task calls for a new document shape; regenerating them from an accidental edit would accept that edit as policy.

For requested policy changes, choose the declaration that expresses the constraint:

FormChecks
headingsExact ordered headings, written as quoted ATX strings such as '## Usage'.
outlinesA section pattern with optional or repeated headings and accepted alternatives.
badgesThe linked-image badge block below the title; combines with headings or outlines.
contentThe entire file, compared byte for byte.

documentation.scan finds undeclared Markdown files. Use intended roots such as ['*.md', 'docs/**/*.md']; a root **/*.md may include dependency documents. max_level limits the checked heading depth. guard init records current README headings as a starting point; review them. Additional documents need declarations.

See the documents schema for outline patterns, badge syntax, and shipped declarations.
