DocGensrc/DocGen/Analysis/Doc/PhpDocParserBridge.php:28
final class PhpDocParserBridge

Parses PHPDoc text for both phpstan/phpdoc-parser 1 and 2.

Version 2 requires a ParserConfig argument on every collaborator while version 1 forbids it, so the constructors are inspected with reflection and the config argument is prepended only when the installed version declares it. This keeps the bridge valid for either major version without referencing classes that only one of them ships.
