final class SourceDigestIndex

Digests the source files a page was documented from.

The documentation of a symbol is decided by the file it is declared in, so the digest of that file answers whether anything the symbol shows could have changed. Files are read at most once per run, because a file that declares one symbol is usually referenced by many pages.
