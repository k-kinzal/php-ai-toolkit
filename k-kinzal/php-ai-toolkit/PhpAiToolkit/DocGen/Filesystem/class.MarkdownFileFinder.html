final class MarkdownFileFinder

Finds the Markdown documents of a package directory.

Documentation written next to the code is part of what a reader needs, so every Markdown file below the package is collected. Dependency, build, and hidden directories are pruned: they hold documents of other projects or generated output, neither of which belongs to this package.
