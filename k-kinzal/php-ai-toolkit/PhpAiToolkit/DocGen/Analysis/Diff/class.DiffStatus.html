final class DiffStatus

The four states one documented element can have in a diff.

A plain constant holder is used instead of a native enum to keep the toolkit compatible with PHP 8.0.

public const REMOVED = 'removed'
source§

State of an element that exists only in the base revision.

public const MODIFIED = 'modified'
source§

public const SAME = 'same'
source§

State of an element that is identical in both revisions.

Methods§

public function combine(list<string> $statuses): string
100%source§

Combines the states of the parts of one element into its own state.

Parts that disagree make the container modified rather than added or removed, so a container is only ever called new or gone when every part of it agrees, and a container that holds one change is never hidden as unchanged.
