final class RequirePhpDocOnPublicApiRule
    implements Rule<ClassLike>

Requires PHPDoc comments on all public API elements.

Checks classes, interfaces, traits, enums, their public methods (including magic methods), public properties, and public constants. Classes in restricted test namespaces are excluded entirely.
