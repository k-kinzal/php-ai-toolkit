final class AnswerScript

Decides what a fake provider answers to each question about each subject.

Without a closure every predicate holds with certainty, every choice picks its first option and every score lands on its top level, so a fake run reports no violation of the shipped rules. A closure receives the question and the subject sections and returns the answer, or null for the default.
