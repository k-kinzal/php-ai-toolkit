abstract class LegacyDoctestRunner
    extends TestCase

Base class for running doctests as PHPUnit 9 tests.

PHPUnit 9 reads test metadata from doc-comments rather than from attributes, so the provider is bound with an annotation here and with an attribute in DoctestRunner. Projects on PHPUnit 10 or later should extend that class: doc-comment metadata was removed in PHPUnit 12.

PHPUnit 9 also has no extension API, so a suite on that version implements configure() itself rather than reading parameters from phpunit.xml.
