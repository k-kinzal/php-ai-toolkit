final class NamespaceLineage
Restricted visibility: declared "@visibility parent". Code outside that scope must not name this declaration.

Answers the namespace ancestry questions a visibility scope is built from.

A namespace behaves like a Rust module: it holds its own declarations and, transitively, everything declared below it. Every scope ScopeGuard resolves is one namespace plus that subtree, so ancestry is the only arithmetic needed.
