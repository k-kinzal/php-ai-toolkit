classSidebarHtml

DocGensrc/DocGen/Render/Page/SidebarHtml.php:23
final class SidebarHtml

Renders the navigation sidebar shared by all pages.

The sidebar is scoped to the current page rather than to the whole project: it lists the sections of the page, then narrows from the widest scope to the narrowest — the entry points and layers of the package first, then the namespace with the symbols that sit next to this page.
