final class TestCase

One test case that exercises a documented class or member.

A test case is evidence that the documented symbol behaves as described, so it is modelled as a test identity rather than as a call site. The origin records how the link was established: line coverage attributes the symbol's own lines to a test, a call is a statically resolved reference to the symbol from a dev source file, and both may hold at once.
