DocGensrc/DocGen/Analysis/Reference/UsageCollector.php:48
final class UsageCollector
    implements NodeVisitor

AST visitor that records references to documented symbols.

Method call receivers are resolved only from statically certain sources, namely $this, typed parameters, typed properties, and direct construction, so the reported call sites contain no guesses.
