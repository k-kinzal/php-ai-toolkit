final class SequenceMatcher

Matches items against an ordered list of slots, each required once, optional, or repeatable.

The matcher finds the alignment with the fewest findings, where each skipped item and each unfilled required slot is one finding. A repeatable wildcard slot therefore never swallows an item a later slot needs, and a renamed section is reported once as missing instead of failing every heading after it.
